# ip-lavrichenko

Официальные документы ИП Лавриченко Анастасии Юрьевны. Сайт публикуется через GitHub Pages:
https://lavrilook.github.io/ip-lavrichenko/

| Файл | Что внутри |
|---|---|
| `index.html` | Главная: список документов, контакты и реквизиты |
| `offer.html` | Публичная оферта на создание визуального контента (нейровизуал) |
| `bot-offer.html` | Оферта Telegram-бота @pay_lavri_ai_bot (библиотека промптов, консультации) |
| `privacy.html` | Единая политика обработки персональных данных (заказы, контрагенты, бот) |
| `styles.css` | Общие стили, мобильная и печатная версии |

Оферта бота и политика дублируются в боте (`/oferta`, `/privacy` в репозитории pay-bot) — тексты должны совпадать.
При изменении документа меняется дата редакции; старые заказы остаются на условиях редакции на дату оплаты.

Не добавляйте сюда секреты, клиентские материалы, паспортные данные, адрес регистрации и телефон.
