## Локальная работа

Зависимостей и этапа сборки нет. Python 3 нужен только для локального сервера:

```sh
cd /workspace/ip-lavrichenko
python3 -m http.server 8000 --bind 127.0.0.1
```

Для проверки пути GitHub Pages запустите сервер из `/workspace` и запросите `/ip-lavrichenko/`. Все внутренние ссылки относительные; внешних шрифтов, JavaScript, форм, аналитики и платёжного интерфейса нет. Не добавляйте сюда секреты, клиентские материалы, уведомления с непубличными данными или банковские документы.
